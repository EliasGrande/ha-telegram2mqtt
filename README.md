# ha-telegram2mqtt

Telegram2MQTT for Home Assistant app repositories.

What this app does:
- Listens to a `send` MQTT command topic and forwards messages to Telegram.
- Publishes `availability` and `state` MQTT topics for Home Assistant automations.
