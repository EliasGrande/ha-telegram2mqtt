# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-08-22

Initial public migration release from a private self-hosted repository to GitHub.

### Changed
- Updated all repository references to `ha-telegram2mqtt`.
- Updated repository URLs to `https://github.com/EliasGrande/ha-telegram2mqtt`.
- Updated user-facing wording to "app" across metadata and docs.
- Reworked README and DOCS with complete installation, configuration, and MQTT contract details.
- Updated agent configuration for VS Code custom agent workflows.

### Compatibility
- Maintained support for both `/data/options.yaml` and legacy `/data/options.json`.
- Documented legacy JSON support as a future deprecation candidate (not removed).
